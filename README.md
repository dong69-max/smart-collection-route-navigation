# My App

Built with [Kliv](https://kliv.dev) — the AI-powered platform for building web applications through conversation.

## Getting Started

This project uses React, TypeScript, Tailwind CSS v4, and shadcn/ui.

### Run locally

```bash
npm install
npm run dev
```

### Tech stack

- **React 18** with TypeScript
- **Tailwind CSS v4** for styling
- **shadcn/ui** component library
- **React Router** for navigation
- **TanStack React Query** for data fetching
- **Recharts** for charts and visualizations
